# 21Growth Studio

Web nueva de 21Growth (vídeo vertical y Meta Ads, Madrid). Sitio estático sin dependencias: HTML, CSS y JS.

## Ver en local
Abre `index.html` en el navegador, o ejecuta `python3 -m http.server` y entra en http://localhost:8000.

## Editar
- Textos: `index.html`
- Estilo y animaciones: `styles.css`
- Interacciones: `main.js` (`CONTACT_EMAIL`: correo de contacto)
- Logo: `logo.svg`

## Publicar
GitHub Pages: Settings > Pages > Deploy from a branch > main / root.
